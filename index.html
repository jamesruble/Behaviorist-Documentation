Directions & Definitions

Aggression — tally

Hitting others with an open hand, closed hand, or object. Enter one total for the day. Use interval detail only when time-block analysis is specifically needed.

Self-Injurious Behavior — tally

Hitting their own head with an open hand, closed hand, or object. Enter one total for the day. Use interval detail only when time-block analysis is specifically needed.

Screaming — partial interval

Select + when the defined behavior was observed during the interval, - when it was not observed, and Ø when the student was absent or data was not collected. The percentage is calculated as + intervals divided by + and - intervals; Ø is excluded.

Visual Inspection by Time Block

In Daily Total mode, Aggression and SIB display as a daily-total chart. Switch to Interval Detail only when you need to see where those frequency behaviors occurred during the day. The +/− behavior remains graphed by interval.

Prototype Disclaimer

This application is a demonstration prototype and is not approved or finalized for production use. It is not currently connected to a SharePoint database, Power Apps environment, Power Automate workflow, or permanent student record system. Information entered here remains in the current browser session until an updated workbook is exported. A previously exported workbook can be loaded to continue the same student record, review an existing date, or add another day. The companion workbook generator creates editable Excel tables, formulas, and native Excel line charts that update when source values change. Loading the workbook restores the continuing student record. The interface, permissions, signatures, retention requirements, student-specific configurations, and reporting workflow must still be reviewed before production use.
